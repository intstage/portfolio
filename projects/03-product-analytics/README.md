# Продуктовая аналитика рейсов

> Компания: туроператор речных круизов. Цифры и названия рейсов скрыты.

## Задача
Понять заранее, какие рейсы продаются хуже, чем нужно, чтобы успеть запустить продвижение или скидки.

## Решение
- Загрузка рейсов, броней и мест из BI-витрин (SQL в Superset) по API.
- Статус каждого рейса: «в норме / проблема / рано» — «проблема» считается только для рейсов в ближайшие 60 дней, дальние не шумят.
- Сравнение с тем же периодом прошлого года (YoY).
- Отчёт в Telegram Mini App с той же системой карточек, что и в других отчётах (значение + отклонение + база сравнения).
- Тесты расчётов перед каждым выпуском.

## Результат
Отдел продаж видит проблемные рейсы в окне 60 дней до отправления. Следующий этап сформирован по отзывам пользователей отчёта.

**Стек:** `SQL` `Superset API` `Google Apps Script` `Telegram Mini App`
