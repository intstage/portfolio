# «Штаб аналитики»: порядок в данных и процессах

> Как я организовал работу единственного аналитика с 10+ проектами.

## Задача
Много параллельных отчётов, ботов и интеграций; знания жили в чатах и в голове. Риск: если аналитик в отпуске, всё останавливается.

## Решение
- **Git** для всего кода (Apps Script выгружается через `clasp`), выпуск только после проверки.
- **`STATE.md` в каждом проекте** (статус, версия, следующий шаг, блокер) → скрипт на Python собирает сводную панель проектов.
- **Pre-commit хук** блокирует коммит, если в нём выгрузки с персональными данными или ключи API.
- **Словарь метрик:** одна цифра — одно определение, SQL-эталон каждой метрики.
- **Журнал решений, реестр доступов (без значений), инструкция «если меня нет».**
- **Карта целей:** цель → 3 направления (видеть / знать клиента / возвращать) → задачи → проекты → метрики. Доска задач в GitHub Projects.
- **AI-ассистент (Claude Code)** как инструмент разработки: правила работы с данными записаны для него явно.

## Результат
Любой проект можно передать коллеге по одному файлу; выгрузки с ПДн и ключи отсекаются автоматически ещё до коммита.

**Стек:** `Git` `GitHub Projects` `Python` `clasp` `Claude Code`
