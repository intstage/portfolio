# Пет-проект: торговый бот для TON

> Личный проект, код в закрытом репозитории. Режим по умолчанию — бумажная торговля в тестовой сети.

## Что делает
Бот ребалансирует портфель TON/USDT через DEX (основной STON.fi, резервный DeDust). Управление и уведомления — Telegram-бот.

## Интересное с точки зрения данных
- Котировки из двух источников с таймаутом и фолбэком.
- Стратегия ребалансировки по целевой доле и порогу отклонения.
- Риск-менеджер: лимит сделки, пауза между сделками, предел влияния на цену и доли издержек (комиссия + газ + slippage), дневной лимит убытка.
- Симуляция исполнения с проскальзыванием; журнал сделок в SQLite, сводка P&L по команде.
- Тройной предохранитель от случайного запуска на реальные деньги, секреты только в `.env`.

**Стек:** `TypeScript` `Node.js` `SQLite` `Telegram Bot API` `TON` `Vitest`
