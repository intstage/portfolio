# Пет-проект: домашний сервер для данных и ботов

> Личный проект: старый ноутбук на Windows работает как сервер 24/7. Адреса, имена машин и учётные записи не раскрываются.

## Задача
Боты и ночные задачи не должны зависеть от того, открыт ли мой Mac. Рабочие файлы нужны и на компьютере, и на сервере, и с телефона, а без бэкапа одна ошибка синхронизации может стереть их сразу на всех машинах.

## Решение
- **Сервер:** ноутбук всегда от сети, работает с закрытой крышкой, сон отключён, после перезагрузки сам входит в систему и блокирует экран.
- **Удалённый доступ:** SSH только по ключам, частная сеть Tailscale (mesh VPN) между Mac, сервером и телефоном, запасной путь — программа удалённого рабочего стола.
- **Синхронизация:** рабочая папка Mac ⇄ сервер через Syncthing в обе стороны; зависимости (`node_modules`, venv, кэши) не синхронизируются, у каждой машины свои; конфликты сохраняются рядом, а не перезаписывают файл.
- **Бэкапы:** каждый вечер Mac (launchd) кладёт архив рабочей папки на диск данных сервера, хранятся 14 последних — страховка от ошибок синхронизации.
- **Задачи по расписанию:** торговый бот ([кейс 07](../07-ton-trading-bot/)), ежедневная публикация данных в GitHub, сторож VPN-подключения, медиасервер.
- **ИИ-агент на сервере:** Claude Desktop с удалённым управлением с iPhone; общие инструкции для агента лежат в синхронизируемой папке, поэтому проект, начатый на одной машине, можно продолжить на любой другой.
- **Правила безопасности для агента:** смотреть логи и статусы — можно, любое изменение — только после подтверждения; удаление, права, SSH, VPN и всё, что связано с деньгами, — отдельным подтверждением.
- **Обходы ограничений сети:** пакеты Python, недоступные с сервера, скачиваются на Mac под Windows-платформу и ставятся офлайн.

## Результат
Боты и выгрузки работают круглосуточно без участия Mac, рабочая папка одинакова на всех машинах и каждый день попадает в архив, а управлять сервером можно с телефона.

**Стек:** `Windows` `PowerShell` `OpenSSH` `Tailscale` `Syncthing` `launchd` `Планировщик заданий` `Node.js` `Python` `Claude Code`
