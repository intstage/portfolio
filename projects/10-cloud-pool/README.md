# Пет-проект: одно облако из нескольких бесплатных Google Дисков

> Личный проект на домашнем сервере ([кейс 09](../09-home-server/)). Аккаунты, ключи и адреса не раскрываются.

## Задача
У каждого Google-аккаунта 15 ГБ бесплатно. Нужно собрать несколько аккаунтов в один диск, который виден на Windows и в Finder на Mac, а личные файлы хранить зашифрованными, чтобы облако видело только шифротекст.

## Решение
- **rclone:** четыре Google Диска подключены через собственный OAuth-клиент; поверх каждого — шифрующий слой (crypt), всё собрано в один каталог по аккаунтам.
- **Диск в системе:** монтирование через WinFsp как обычный диск «Облако» на сервере, кэш файлов на диске данных с ограничением размера.
- **Доступ с Mac:** раздача по WebDAV только внутри частной сети Tailscale, вход по паролю; в Finder это обычный сетевой том.
- **Два вида папок на каждый аккаунт:** «шифр» — зашифрованные файлы, «открыто» — весь Google Диск как есть, чтобы видеть и файлы, загруженные через сайт; служебные зашифрованные данные скрыты фильтром.
- **Автозапуск и бэкап:** задача планировщика поднимает диск при входе в систему, конфигурация копируется каждый день, хранятся 14 копий; ключи шифрования — в менеджере паролей.

## Что выяснил замерами
- **Скорость с сервера:** Google — около 5,5 МБ/с, Яндекс.Диск по WebDAV — около 0,01 МБ/с (ограничение на стороне сервиса, не VPN). Решение по данным: Яндекс в общий диск не включать.
- **Медленная связь Mac ↔ сервер:** трафик Tailscale шёл через ретранслятор, потому что VPN-клиент на сервере менял внешний UDP-порт. Смена режима туннеля дала прямое соединение и рост скорости примерно в 5 раз.
- **Ограничения:** WebDAV не отдаёт объём диска, поэтому Finder не показывает «занято / свободно»; объединение с дублирующими слоями удваивает объём в отчётах — такие схемы отброшены.

## Результат
Один диск примерно на 60 ГБ из бесплатных аккаунтов, доступный с сервера и с Mac, с шифрованием личных файлов и ежедневной копией настроек.

**Стек:** `rclone` `crypt` `WinFsp` `WebDAV` `Tailscale` `Google Drive API` `OAuth` `PowerShell`
