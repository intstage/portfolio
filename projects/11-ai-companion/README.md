# Пет-проект: Clawdy — голосовой ИИ-компаньон для Mac

> Личный прототип: старый iPhone под монитором превращается в пиксельного крабика, который видит экран Mac, отвечает голосом и умеет сам кликать.

## Что делает
- Зажимаешь экран iPhone и говоришь фразу; крабик видит экран Mac, отвечает голосом, показывает нужное место оранжевым курсором, а по просьбе сам кликает и печатает.
- Глаза крабика следят за мышью, настроение отражается на лице; на Apple Watch — то же лицо и кнопка для надиктовки.
- Можно спросить и прямо с Mac, из строки меню.

## Как устроено
- **Mac:** приложение в строке меню. Два режима обращения к Claude: через Claude Code по подписке (инструменты — скриншот, клик, ввод, «показать», «сказать» — отдаёт встроенный MCP-сервер, который слушает только локальный адрес и требует токен) или через Claude API с инструментами управления компьютером.
- **iPhone:** распознавание речи на русском, озвучка, сканер QR для связи с Mac, мост к часам. **Apple Watch:** зеркало крабика и кнопка микрофона.
- **Защищённый канал Mac ↔ iPhone:** поиск по Bonjour в локальной сети, секрет 256 бит передаётся только QR-кодом, проверка HMAC по случайному вызову, шифрование ChaCha20-Poly1305 с ключами по направлениям (HKDF); повтор или подмена записи рвут соединение. Ключи хранятся в связке ключей и на телефон не уходят.
- **Безопасность действий:** перед необратимыми действиями (отправка, удаление, покупки, пароли, системные настройки) крабик спрашивает подтверждение; текст с экрана считается данными, а не командами; курсор и реплики не попадают в скриншоты; есть горячая клавиша «стоп».

## Чему научился
Проектировать инструменты для ИИ-агента (MCP), ограничивать его права и защищать канал между устройствами без облачного посредника.

**Стек:** `Swift` `SwiftUI` `AppKit` `watchOS` `Claude API` `Claude Code` `MCP` `Speech` `CryptoKit` `Bonjour` `xcodegen`
